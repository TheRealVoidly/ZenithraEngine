# About
A lightweight game engine written in C using SDL2.
It uses SDL2's rendering API, but all scene logic and rendering structure are implemented in my own engine layer.

This project started as a learning exercise in C and systems programming. It focuses on things like memory handling, basic engine structure etc.

## Build

You’ll need SDL2 installed.

Linux: make

Windows: make windows

## Notes

It’s not meant to be a full game engine or anything production-ready. More of a long-term experiment in low-level C programming.
